# Contributing

Corrections are welcome, especially when PS5 homebrew projects change quickly.

## Before opening an issue
Please include:
- Guide page or section.
- PS5 firmware.
- Project/tool name and version.
- What the guide currently says.
- What changed or failed.
- A link to upstream documentation, release notes, or source when possible.

## Pull requests
Keep changes focused and cite upstream sources for technical claims. Do not bundle third-party binaries into this repository.

## Do not submit
- Games, ROMs, disc images, BIOS/firmware dumps, console keys, credentials, private IP addresses, or pairing PINs.
- Pirated content or links to unauthorized copyrighted downloads.
