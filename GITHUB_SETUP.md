# Publish v1.1.0 on GitHub

**English repository only.** Upload the CONTENTS of `repository/` into the EN repo root, not an extra `repository` directory.

1. Push the repo files (including hidden `.github`, `docs`, `tools`, `assets`).
2. Check README badges, edition-specific links and rendered docs.
3. Create GitHub Release tag `v1.1.0` and attach PDF/DOCX plus source helper ZIP from `release-assets/`.
4. Publish the AR Full Pack separately to the Arabic repository.
5. Never publish BIOS, game ISO/XISO, virtual HDD, encryption keys, private IPs, pairing data or third-party prebuilt emulator executables.
