# Build scope and licenses

Only the script sources from this pack are included. The upstream emulator sources are downloaded during user builds and keep their own upstream licenses. This pack does not include prebuilt eboot.bin, payloads, BIOS, games, keys, saves or console credentials.

- CEMU v3.0.0 /app0 patch: observed compiling and 3DS boot tested on one FW13.40 setup.
- Porpoise, XPSemu, PS5X360 script branches: NOT build/boot verified with this release; no need to run them when working versions already exist.
- Important: updating a custom /app0 build to a stock release can revert the custom game paths.
