# حزمة تعديل محاكيات PS5 لوضع ألعاب USB عبر `/app0`

هذه الحزمة لا تحاول إجبار التطبيق على رؤية `/mnt/usb0` من داخل الـ sandbox. بدل ذلك تستخدم طريقة أكثر ثباتًا:

1. يوضع **مجلد التطبيق نفسه على USB** تحت `/mnt/usb0/homebrew/PPSAxxxxx/`.
2. ShadowMountPlus يسجّل التطبيق من USB.
3. داخل التطبيق يظهر مجلد التطبيق دائمًا باسم `/app0`.
4. الألعاب تكون داخل مجلد التطبيق (قراءة فقط)، بينما السيفات/الكاش/الإعدادات تبقى في `/data`.

بهذا لا يعتمد تشغيل الألعاب على ظهور `/mnt` داخل التطبيق.

## المسارات الناتجة

- PS5CEMU-HAR (Wii U): `/app0/roms/wiiu`
- PS5CEMU-HAR (3DS): `/app0/roms/3ds`
- Porpoise (GC/Wii): `/app0/roms`
- XPSemu (Original Xbox): `/app0/roms`
- PS5X360: يستخدم أصلًا `/app0/assets/roms`، لذلك لا يحتاج تغيير مسار أساسي؛ الحزمة تثبّت seed لهذا المسار.

## مهم

- ملفات الكتابة تبقى داخل `/data`: السيفات، الكاش، الإعدادات، MLC/SDMC/HDD وغيرها.
- XPSemu: `xbox_hdd.qcow2` وBIOS وMCPX تبقى في `/data/xemu/` لأنها ملفات نظام/كتابة، وليس `/app0`.
- PS5CEMU-HAR: تحديثات/DLC المثبتة وMLC و3DS SD/NAND تبقى في `/data/ps5cemu/`.
- لا تضع نسختين من نفس Title ID في `/data/homebrew` وUSB وقت الاختبار. احتفظ بنسخة احتياطية خارج مسارات ShadowMountPlus.

## الاستخدام السريع على WSL

فك الحزمة ثم:

```bash
chmod +x build_usb_patched.sh
./build_usb_patched.sh cemu
```

القيم المدعومة:

```text
cemu
porpoise
xpsemu
x360
all
```

السكربت ينزل السورس الرسمي، يطبق التعديل، ويسجل كل ملف تم تغييره في `PATCH_REPORT.txt` داخل المستودع.

## بعد البناء

استخدم:

```bash
python3 scripts/postbuild_layout.py <اسم المحاكي> <مسار مجلد التطبيق الناتج>
```

السكربت الرئيسي يفعل ذلك تلقائيًا عندما ينجح البناء.

ثم انسخ مجلد `PPSAxxxxx` الناتج كاملًا إلى:

```text
/mnt/usb0/homebrew/
```

وبعد تشغيل ShadowMountPlus، المسار `/app0/...` سيشير إلى ملفات التطبيق الموجودة فعليًا على USB.

## لماذا هذا أفضل في حالتك؟

على جهازك ظهر أن Web File Manager وShadowMountPlus يريان `/mnt/usb0`، لكن بعض التطبيقات لا ترى `/mnt` داخل namespace الخاص بها. `/app0` على العكس موجود للتطبيق دائمًا. لذلك نستغل ShadowMountPlus لتركيب التطبيق من USB ونجعل مكتبة الألعاب جزءًا مقروءًا من `/app0`، بدون نقل عشرات/مئات الجيجا إلى SSD الداخلي.

## حماية ضد مسح Build سابق - تحديث 1.1.0
النسخة المرفقة الآن **ترفض** إعادة استنساخ المشروع إذا كان مجلد العمل موجودًا، بدل `rm -rf` الصامت.
إذا توقّف بناء CEMU عند Azahar لا تعِد `build_usb_patched.sh cemu`؛ استخدم خطوات submodules و`--reconfigure` ثم `make release` الموجودة في دليل GitHub.

**حدود التحقق:** الذي بُني واختُبر بنجاح هو CEMU/3DS، أما سكربتات Porpoise وXPSemu وPS5X360 فهي أدوات سورس تجريبية وليست وعودًا بأن البناء أو تصحيح الألعاب نجح.
هذه الحزمة لا تتضمن ملفات ألعاب أو BIOS أو مفاتيح أو ملفات تشغيل مملوكة لمشاريع المحاكيات.
